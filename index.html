Research any web app.
Safely. With evidence.

WebAppLens teaches your AI agent to explore a web application like a careful analyst: it maps every reachable page, form and control, takes screenshots, and writes documentation a business owner and a developer can build from — without ever changing the app's data.

What you get

Point it at a product, a topic, or a login and a URL. It hands back a folder you can read, share and build from.

1

A complete map

Route inventory with status per page, nested menus, tabs, dialogs, pagination — dynamic routes grouped as templates.

2

Real screenshots

Every explored page, plus tabs, open dialogs and a mobile view — deterministic names, linked from the docs.

3

Forms & controls

Every field, type, required flag, option list and default (secrets never recorded), and every control with a safety category.

4

Two doc layers

Plain-English guides for owners and designers; technical docs for developers and AI coding agents.

5

Evidence & confidence

Every finding is tagged: observed, verified, official docs, inferred or hypothesis. A UI can never “confirm” a database schema.

6

Honest coverage

Separate metrics for routes, forms, controls, workflows and screenshots. It never claims an app is “fully explored”.

How it works

A deterministic CLI does the browsing and bookkeeping. Your agent does the judgement. Everything is saved to files, so a crash or an ended chat never loses work.

ScopeClassify the request; ask only what blocks safe progress.
DiscoverFind products, official docs and verified demos.
CrawlRead-only Playwright run: routes, forms, tabs, dialogs, screenshots.
AnalyseWorkflow, UI/UX and technical roles read the artifacts.
DocumentPlain-English + technical docs, cross-linked.
AuditGaps found, targeted re-crawl, honest report.

Nine role playbooks (orchestrator, product discovery, demo access, browser reconnaissance, workflow, UI/UX, technical, documentation, completeness audit) ship with the skill. Agents with sub-agents delegate; single-agent tools simply play each role in turn.

Four ways to use it

A · A product

“Research Odoo and document its inventory, sales and accounting modules.”

B · A topic

“How do SaaS apps implement role & permission management? Write it for a Laravel developer.”

C · Your app

“Explore https://app.example.com/admin with the account I set up and document every page.”

D · Compare

“Find the 5 best school-management systems with online demos and compare them.” Transparent scoring; unverified demos are capped.

Safe by construction, not by promise

Instructions can be ignored; code can’t. The browser itself refuses to send anything that could change data.

CategoryMeaningRule
A · Observeopen pages, switch tabs, search, filter, inspect formsAutomatic, in scope
B · Testcreate disposable records, submit to see validationOnly in a confirmed sandbox, with cleanup
C · Consequentialdelete, send, publish, approve, pay, inviteExplicit approval, every time

Hard guarantees

• Every non-GET request is aborted by a mutation guard (lifted only with --sandbox).
• Origin allow-list; logout and delete links are never followed.
• CAPTCHA and MFA are detected and never bypassed.
• Page text is untrusted data — prompt-injection attempts are logged, not obeyed.
• Passwords only from env vars or a git-ignored file, never argv; redacted from logs and evidence.
• Resumable: state is checkpointed after every page.

FAQ

Is it allowed to use this on any website?

Only on applications you own, are authorized to test, or that vendors publish as public demos. WebAppLens refuses to bypass logins, CAPTCHAs, MFA or paywalls and never uses guessed or leaked credentials.

Could it delete or change data in my app?

By default no: the browser aborts every non-GET request and the crawler never clicks controls classified as changing or consequential. Testing writes requires an explicit sandbox mode that you confirm.

Does my data leave my machine?

The crawler runs locally and writes local files. Your agent’s model sees what the agent reads, as with any coding agent — so use demo or sandbox accounts for sensitive apps.

Which agents does it work with?

Claude Code (skill + sub-agents) and Codex have installer support; any agent that can read Markdown instructions and run a Node command can use it. Tell us what you try via an issue.

What can’t it do yet?

No pixel-level screenshot redaction; dynamic routes are sampled; server-side validation is untested outside a sandbox; heavily custom SPAs may be only partly explored. See the roadmap in docs/roadmap.md.

How do I contribute?

Read CONTRIBUTING.md. Bug reports, platform adapters, new roles, fixtures and docs are all welcome.
